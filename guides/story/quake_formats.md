- [.bsp](https://quakewiki.org/wiki/Quake_BSP_Format "Quake BSP Format"): [Level](https://quakewiki.org/w/index.php?title=Level&action=edit&redlink=1 "Level (page does not exist)") (suitable for playing) or static inanimate model
- [.cfg](https://quakewiki.org/wiki/Config_files "Config files"): Configuration file
- [.dem](https://quakewiki.org/w/index.php?title=.dem&action=edit&redlink=1 ".dem (page does not exist)"): Quake [demo](https://quakewiki.org/w/index.php?title=demo&action=edit&redlink=1 "demo (page does not exist)"), a recorded gameplay session
- [.lmp](https://quakewiki.org/wiki/.lmp ".lmp"): 2D HUD/UI graphics, also [palette.lmp](https://quakewiki.org/wiki/palette.lmp "palette.lmp") and [colormap.lmp](https://quakewiki.org/wiki/colormap.lmp "colormap.lmp") (sort of a catch-all extension)
- [.map](https://quakewiki.org/wiki/Quake_Map_Format "Quake Map Format"): Uncompiled level (must be compiled into a.bsp before playing)
- [.mdl](https://quakewiki.org/wiki/mdl "mdl"): [Model](https://quakewiki.org/wiki/Model "Model") (3D asset for in-game entities)
- [.pak](https://quakewiki.org/wiki/.pak ".pak"): File archive, contains many files of other types
- [.rc](https://quakewiki.org/w/index.php?title=.rc&action=edit&redlink=1 ".rc (page does not exist)"): Configuration file
- [.spr](https://quakewiki.org/w/index.php?title=.spr&action=edit&redlink=1 ".spr (page does not exist)"): [Sprite](https://quakewiki.org/w/index.php?title=Sprite&action=edit&redlink=1 "Sprite (page does not exist)") (2D asset for in-game entities)
- [.wad](https://quakewiki.org/wiki/Texture_Wad "Texture Wad"): Quake [Textures](https://quakewiki.org/wiki/Textures "Textures") for map compiling, also [gfx.wad](https://quakewiki.org/w/index.php?title=gfx.wad&action=edit&redlink=1 "gfx.wad (page does not exist)")
- [.wav](https://quakewiki.org/w/index.php?title=.wav&action=edit&redlink=1 ".wav (page does not exist)"): Waveform audio format

### Ironwail extended formats

- `.jpg`, `.png`, `.tga`: External texture replacements (drop in `textures/` folder)
- `.md3`: Quake III model format, supported by Ironwail
- `.ogg`: Ogg Vorbis audio, supported alongside `.wav`
- `.lit`: Colored lightmap definition
