**Map Compiling** is the process of converting a [level](https://quakewiki.org/w/index.php?title=level&action=edit&redlink=1 "level (page does not exist)") from a [map file](https://quakewiki.org/wiki/Quake_file_formats "Quake file formats"), which generated by a [level editor](https://quakewiki.org/w/index.php?title=level_editor&action=edit&redlink=1 "level editor (page does not exist)"), into a [bsp file](https://quakewiki.org/wiki/Quake_file_formats "Quake file formats"), which is ready to be played in-game. It generally consists of three steps: [QBSP](https://quakewiki.org/wiki/QBSP "QBSP"), [Light](https://quakewiki.org/wiki/Light_\(map_compiling\) "Light (map compiling)"), and [Vis](https://quakewiki.org/wiki/Vis "Vis").

## QBSP

*Main article: [QBSP](https://quakewiki.org/wiki/QBSP "QBSP")*

**QBSP** is the first stage of map compilation. It is the process that reads the map file and generates the bsp, and in doing so calculates all of the geometry and collision data for the level. It also extracts any needed textures from the [wad files](https://quakewiki.org/w/index.php?title=wad_file&action=edit&redlink=1 "wad file (page does not exist)") and repackages them into the bsp file. After this step, the level can be loaded into the game engine. However, it will not have any lighting (everything will be fully bright) or visibility (the game might run slowly) data.

## Vis

*Main article: [Vis](https://quakewiki.org/wiki/Vis "Vis")*

**Vis** is the stage of map compilation that calculates [PVS](https://quakewiki.org/w/index.php?title=PVS&action=edit&redlink=1 "PVS (page does not exist)") data for the level. With PVS data, the engine need only draw those parts of the level (and those entities) that might be visible from the current player location. This performance optimization was necessary to allow levels as large and as complex as Quake's on the computers of the day. And even today, most games use equivalent systems to allow levels, props, and NPCs to be as detailed as possible.

## Light

*Main article: [Light (map compiling)](https://quakewiki.org/wiki/Light_\(map_compiling\) "Light (map compiling)")*

**Light** is the stage of map compilation that calculates [lightmaps](https://quakewiki.org/w/index.php?title=lightmap&action=edit&redlink=1 "lightmap (page does not exist)") for the level. Using the light entities from the [entity lump](https://quakewiki.org/w/index.php?title=entity_lump&action=edit&redlink=1 "entity lump (page does not exist)") of the bsp file, it precalculates the lighting on every surface in the level, and saves that lighting as lightmaps in the bsp file.
